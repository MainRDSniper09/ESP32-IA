# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: sea respetuoso e inclusivo, acepte las críticas constructivas, céntrese en lo
mejor para la comunidad y no tolere el acoso de ningún tipo.

Para reportar un comportamiento inaceptable, contacte al mantenedor a través de su perfil
de GitHub. Todas las quejas se revisarán con confidencialidad.
